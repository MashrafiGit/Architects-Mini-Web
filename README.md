# G3 Architects Landing Page 🏗️

🔗 **Live Demo:** https://architects-mini-web.vercel.app/

This is a **practice frontend project** built using **HTML and CSS**.  
The project represents a professional **architects / construction company landing page** with multiple well-structured sections focused on layout, responsiveness, and clean UI design.

The main goal of this project was to practice **real-world landing page structure**, **Flexbox & Grid layouts**, and **responsive design** for desktop, tablet, and mobile devices.

---

## 🛠 Tech Stack
- HTML5  
- CSS3  
- Google Fonts (Work Sans)  
- CSS Flexbox  
- CSS Grid  
- Media Queries  

---

## ✨ Features
- Responsive navigation bar  
- Hero / banner section with call-to-action  
- Team showcase section with image grid  
- Feature highlights section with cards  
- Experience badge overlay design  
- Statistics / facts section  
- Sponsors & partners section  
- Clean footer section  
- Fully responsive layout across devices  

---

## 📱 Responsiveness
- **Desktop:** Multi-column professional layout with proper spacing  
- **Tablet:** Stacked sections with balanced typography and grids  
- **Mobile:** Single-column layout optimized for readability  
- Images scale responsively while maintaining aspect ratio
